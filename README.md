
# Storage Estimator



## Purpose

A simple Python program that calculates the total storage needed for a number of files of the same size, in MB and KB.



## How to Run

Run the program with:



    python storage_estimator.py



Enter the file size in MB, then the number of files.



## Example

Input:



    Enter file size in MB: 10

    Enter number of files: 4



Output:



    === Storage Estimator ===

    Number of files: 4

    Total size (MB): 40.0

    Total size (KB): 40960.0
