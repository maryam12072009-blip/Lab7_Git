# Storage Estimator - Main Version



## Purpose

A simple Python program that calculates the total storage needed for a number of files of the same size, in MB and KB.



## How to Run

Run the program with:



&#x20;   python storage\_estimator.py



Enter the file size in MB, then the number of files.



## Example

Input:



&#x20;   Enter file size in MB: 10

&#x20;   Enter number of files: 4



Output:



&#x20;   === Storage Estimator ===

&#x20;   Number of files: 4

&#x20;   Total size (MB): 40.0

&#x20;   Total size (KB): 40960.0
